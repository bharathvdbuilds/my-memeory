# Unity Martial Arts Club

Website for Unity Martial Arts Club, a karate and self-defence club in Ananthnagar, Bengaluru.

The app lives in this folder so it stays separate from the other projects in the repository.

## Run locally

```bash
cd unity-martial-arts
npm install
npm run dev
```

Open http://localhost:3000

Production build:

```bash
npm run build
npm start
```

## What is on the page

- Home, About, Programs, Our Coach, Fees, Gallery, and Contact
- Official logo in the navigation and footer
- Limited 24-hour enquiry offer for new students: ₹2,000, valid for 24 hours
- Enquire Now and the offer button open WhatsApp (+91 80504 60145) with the same prefilled message
- Google Maps link supplied by the club
- Enquiry form with a confirmation on the page (no server is required)

Class fees, the coach’s name and rank, and a street address are not published here. The map link did not resolve to a street address, so the page gives the location as Ananthnagar, Bengaluru and links out to Google Maps.
